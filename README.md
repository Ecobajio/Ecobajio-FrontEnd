## 1. Descripcion del Proyecto
EcoBajio es una aplicacion web diseñada para mitigar el estres hidrico y las "islas de calor" en la ciudad de Leon, Guanajuato[cite: 2, 3]. La plataforma permite gestionar el registro, la geolocalizacion y la validacion comunitaria del riego de arboles nativos adoptados por los ciudadanos[cite: 3].

## 2. Objetivo de la Actividad
Construir, de manera colaborativa, un prototipo front-end navegable aplicando HTML5 semantico y CSS3 personalizado. Este prototipo representa los requerimientos funcionales documentados en la Actividad 3, sin depender aun de un backend.

## 4. Tecnologias Utilizadas
*   **Maquetacion:** HTML5 semantico[cite: 1].
*   **Estilos:** CSS3 propio (sin frameworks externos)[cite: 1].
*   **Control de Versiones:** Git y GitHub[cite: 1, 6].

## 5. Vistas del Prototipo
El prototipo consta de un flujo navegable con las siguientes pantallas principales[cite: 1, 6]:
1.  **Pantalla Login:** Interfaz limpia con inputs de acceso y creacion de cuenta.
2.  **Dashboard (Mapa):** Vista central con ubicacion y pines de arboles[cite: 6].
3.  **Registrar Arbol:** Formulario de captura y coordenadas[cite: 6].
4.  **Mis Alertas:** Lista de notificaciones de estres hidrico[cite: 6].
5.  **Verificacion de Riego:** Pantalla para la carga de evidencia fotografica[cite: 6].

## 6. Flujo de Trabajo (Git)
*   Se utilizara un tablero de tareas para asignar cada vista[cite: 1].
*   Se trabajara utilizando ramas individuales por integrante o por vista[cite: 1].
*   Todo el codigo integrado a la rama principal pasara por *commits*, *pull requests* y revision entre pares[cite: 1].
